# GrammarCheck Mobile

Flutter iOS/Android cho ba ứng dụng: tài liệu, hỗ trợ học tiếng Việt và dữ liệu NLP.

Xem [hướng dẫn chung](../../docs/MULTIPLATFORM.md) để chạy API, cấu hình thiết bị và kiểm thử.

```bash
flutter pub get
flutter run
```

API mặc định: http://127.0.0.1:8000. Đổi địa chỉ trong Kết nối khi dùng điện thoại thật hoặc Android Emulator.
